# 收银与商家后台：只保留现行外壳

2026-10-20，本地实现与验证完成；用户已明确授权提交、推送和上线，正在执行静态页面发布。实际发布结果以后续凭证为准。

## 当前有效界面

| 应用 | 电脑 | 手机 |
| --- | --- | --- |
| 收银 | 现行桌台／菜单工作台、侧栏、状态工具区、队列与详情 | 现行 Mobile V2 品牌栏、菜单抽屉、状态筛选、整页详情、固定操作区 |
| 商家后台 | 现行 MerchantLayout 顶部八项管理导航及正式经营分析 | 同一 MerchantLayout 的首页／菜品／订单／结账／更多，按权限显示 |

本轮沿用现有界面，不将收银手机外观强套到电脑，也不重新设计商家后台。原有登录、强制改密、角色与能力权限、数据口径、点菜、收银、聊天及打印业务保持。

## 清理结果

收银移除逐页 `mobileV2Enabled` 白名单，由父级工作区统一标记、按屏幕尺寸选择现行电脑或手机外壳。手机冷启动默认启用现行外壳，只排除登录、改密和独立 KDS；新页面无需再维护多份手机入口清单。未知工作区使用通用标题，不误显示订单历史。

实际删除旧 `CashierMobileNavigation.vue` 与 `LegacyOrderRedirectPage.vue`，同时删除旧手机头部、旧菜单搜索／分类分支、旧账号底栏标记和对应样式。桌台、菜单、历史页也不再依赖单页启用标记。现行电脑头部保留其正常工作台功能。

旧 `/orders/new`、`/orders/active` 链接在鉴权与强制改密检查之后、页面挂载之前解析并进入现行订单归属页面。查询参数变化会重新解析；接口失败使用原有可恢复回退；最终目标仍经过能力权限检查。旧链接本身不再渲染页面或旧导航，保留兼容地址以免已有通知／书签失效。

商家后台实际删除八个已被现行页面替代的文件：

- `DashboardPage.vue`
- `OrdersPage.vue`
- `MerchantProfilePage.vue`
- `PrintersPage.vue`
- `CategoriesPage.vue`
- `ReportSettingsPage.vue`
- `MerchantChangePasswordPage.vue`
- `printing/PrintingTerminalsPage.vue`

旧打印地址直接进入现行打印中心，不再根据旧灰度开关选择页面。分类、设置、改密和 Android 终端历史链接只做新版重定向。无权限内容也放入同一 MerchantLayout，保留导航和返回能力。删除与旧商家侧栏／手机头部关联的专属样式；平台管理端仍在使用的共享样式保留。

旧业务接口、原打印历史和财务审计不是旧页面，不因界面清理而删除。开发隔离预览复用的也是现行外壳，不是可上线的另一套旧页面。

## 验证

- 收银 722 项测试通过，包含未来新增页面自动继承、冷启动、KDS 隔离、旧书签等待期间不提交页面、查询参数变化、登录和强制改密。
- 商家后台全部 package 测试与静态 lint、收银 lint、全项目类型检查与构建通过；独立 KDS 构建输出至临时目录。小程序构建隔离输出，原 canonical 上传目录逐文件哈希相同。
- 收银现行手机版 375／390／430 和电脑版 1024／1280／1440 完整流程回归通过；外部 OpenStreetMap 瓦片采用隔离占位排除 DNS 依赖，不代表地图影像验收。
- 两端入口额外检查 86 组：收银 7 个宽度 × 8 个入口（含未来新页面），后台手机／电脑旧链接、打印旧开关开／关、STAFF 无权限，均进入现行外壳，无脚本错误。
- 后台 136 组路由／宽度、64 组三语手机状态、54 组电脑导航组合通过；10 组基础交互和 9 组深入交互通过，包含草稿、焦点、弹层、权限、打印目录和作废证据。WebKit 因本机缺少对应浏览器运行包未运行，真实 iPhone 主屏幕仍需真机验收。
- 预约隔离真实 API 的 5 项流程、7 组手机列表／详情／聊天、3 组电脑布局通过，包含确认桌号与消息收发；未使用生产数据。
- 设计检查将 MerchantLayout 的 Vue `:src="huayueLogo"` 变量误当成本地路径。已核对其导入的实际 PNG 文件与浏览器截图正常；其余仅为既有组件缺少设计 stamp 提示，没有为消除提示改动现有品牌或图表。

证据见 [验收结果](ui-review/current-shell-cleanup/LOCAL_PASS.json)。本轮没有 API、数据库或小程序源码变更。发布时只需更新收银与商家后台静态制品。
