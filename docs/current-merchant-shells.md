## 2026-10-25 收银打印设备图标

已提交、同步 GitHub main 并上线，代码 `692c117`，版本 `cashier-printer-status-20261025-v1`，详见 [发布记录](release/cashier-printer-status-20261025-v1.md)。商家 325 的反馈经用户澄清为右上角图标显示离线，实际打印没有故障；此前对打印机重启、IP 和协议的排查不作为本次根因。

原图标读取人工打印入口的 USB 可用状态，没有计入已在线的网络打印机。现新增 `deviceAvailability` 供电脑／手机共用外壳读取：任意一台已启用的 USB、Wi-Fi／局域网或云打印机满足服务端 `ONLINE` 和完整 readiness 条件，图标即显示可用；全部离线、没有配置、未开通、正在加载或状态查询失败时沿用现有对应提示。商家开关、执行开关和账号权限仍需通过。

人工打印任务入口继续使用原 `availability`、USB 列表与执行保护；本次仅改变状态图标的数据来源，不改打印协议、设备配置、后端接口或 Windows 安装包。

803 项收银测试、类型检查、lint 与生产构建通过。新增回归覆盖 USB 离线时仅网络／两种云打印在线，以及唯一网络打印机断开或停用；沿用服务端 readiness 缺失、状态查询失败、权限与开关关闭的保护验证。只更新收银静态页，服务器和本机外网各核对全部 69 个发布文件；商家 325 网络打印机 45 的服务端状态为 ONLINE／READY，用户刷新或重开收银页即可加载新版。

## 清理结果

收银移除逐页 `mobileV2Enabled` 白名单，由父级工作区统一标记、按屏幕尺寸选择现行电脑或手机外壳。手机冷启动默认启用现行外壳，只排除登录、改密和独立 KDS；新页面无需再维护多份手机入口清单。未知工作区使用通用标题，不误显示订单历史。

实际删除旧 `CashierMobileNavigation.vue` 与 `LegacyOrderRedirectPage.vue`，同时删除旧手机头部、旧菜单搜索／分类分支、旧账号底栏标记和对应样式。桌台、菜单、历史页也不再依赖单页启用标记。现行电脑头部保留其正常工作台功能。

旧 `/orders/new`、`/orders/active` 链接在鉴权与强制改密检查之后、页面挂载之前解析并进入现行订单归属页面。查询参数变化会重新解析；接口失败使用原有可恢复回退；最终目标仍经过能力权限检查。旧链接本身不再渲染页面或旧导航，保留兼容地址以免已有通知／书签失效。

商家后台实际删除八个已被现行页面替代的文件：

- `DashboardPage.vue`
- `OrdersPage.vue`
- `MerchantProfilePage.vue`
- `PrintersPage.vue`
- `CategoriesPage.vue`
- `ReportSettingsPage.vue`
- `MerchantChangePasswordPage.vue`
- `printing/PrintingTerminalsPage.vue`

旧打印地址直接进入现行打印中心，不再根据旧灰度开关选择页面。分类、设置、改密和 Android 终端历史链接只做新版重定向。无权限内容也放入同一 MerchantLayout，保留导航和返回能力。删除与旧商家侧栏／手机头部关联的专属样式；平台管理端仍在使用的共享样式保留。

旧业务接口、原打印历史和财务审计不是旧页面，不因界面清理而删除。开发隔离预览复用的也是现行外壳，不是可上线的另一套旧页面。
