# YunQiao 平台后台视觉与交互评审

2026-11-05 · 视觉提案与确认记录

此前涵盖平台后台、商家后台电脑页、商家后台手机页、收银电脑页、收银手机页、KDS、微信小程序七种界面，采用线上已登录页面、微信开发工具当前项目和仓库色彩变量共同核对。**最新范围为平台电脑后台；本轮不重构手机后台、商家后台、收银、KDS或小程序。** 当前工作处于设计确认阶段，正式实现以各项确认后的规格为依据。

## 已确认的偏好

- 图表使用折线、柱形或横条，具备清楚的轴、标签、比较线和明细入口。视觉接近用户期望的 Apple 风格，使用克制的留白、清晰的文字层级、轻边界和有效反馈。
- 信息密度适中，常用操作集中，高级筛选折叠。
- 左上角只使用收银同款绿色 Logo 图形与 YunQiao 名称，不添加「平台后台」「PLATFORM ADMIN」或其他小字。原图中占比最高的绿色为 `#008E48`。
- 收银与 KDS 的现有配色获用户认可，作为新方案衔接的基准，当前外框主色为 `#061522`，工作区浅色，关键动作使用深绿。
- 用户要求换一个主色方向，绿琉璃主色方案结束评审。蓝灰与雾白、靛蓝与雾白均未获选择；用户提供 FloShot 网站作为新的学习参考，并明确仅学习配色与动态处理，不直接复制。
- 配色确定后继续确认业务与交互细节，再进入正式实现。
- **最新确认：** 平台后台采用本轮「雾白底＋蓝色主操作＋紫／青辅助色」方向，继续细调；动效选择「更明显、更流畅，有一定展示感」。此确认仅确定视觉方向，不代表业务细节或正式开发已获确认。
- 桌面左侧导航所有分组始终展开，子入口全部保留，不使用折叠分组或折叠箭头。高度不足时侧栏纵向滚动，保持主工作区位置。本轮新增设计与验收范围为电脑后台。
- 商家、订单、用户等列表的详情默认在右侧快速查看。完整编辑从明确的「编辑」入口进入独立页面，保存或返回后恢复原筛选、页码与位置。快速查看以阅读、关联跳转和进入完整页面为主，不把长表单放在右侧。
- 图表默认周期已确认：运营总览看今天；营业分析看近 7 天，并与前 7 天比较。手动修改周期后，本次查询与钻取沿用已生效条件。含今天的数据注明进行中；具体订单／金额口径另行核对。
- 图片张数限制按重构目标放开。**最新规则：单张源图最多20MB，上传后统一自动优化，观感以现有平台照片为基准，服务器不永久保留上传原图。** 此规则替代此前「可切换原图、原图不压缩」的选项。只保存优化后的展示图与列表小图，上传队列、单张进度、失败重试保持一致。新增、编辑、导入共用同一规则，正式实现需将当前5MB限制在前端、接口与上传链路同步调整。
- 公共标签名称修改后同步所有关联商家，并显示影响数量及关联商家入口。保留标签 ID 与用于推荐等业务的内部标识，避免改显示名称破坏已有关系；原有商家无需重新绑定标签。
- 新建商家只需店名＋城市即可保存草稿，其他资料可以后补，草稿不对外展示。
- **公开展示要求按行业资料清单齐全。** 公共资料包括店名、城市、行业、联系人和电话、地址与精确定位、封面、介绍、营业时间；餐饮再补菜单或菜品，酒店补房型，服务商家补服务项目。对外店名、地址和介绍要求中文＋越南文齐全，英文选填。旧代码的 9 项资料完整度不能直接替代新发布清单。不同语言不覆盖彼此已有的有效内容。
- 已公开商家修改介绍、图片或所选标签后，点击「保存并更新」对外生效，也可以另存草稿。草稿保存与对外更新入口明确分开；对外更新按完整资料清单校验，未发布的修改不覆盖当前生效内容。
- 新标准启用时，现有已展示但资料不齐的商家保留展示，列入待完善清单，显示缺少哪些资料及完善入口；不按新清单批量隐藏既有门店。新建草稿首次公开和后续「保存并更新」按新的完整资料清单校验，既有展示版本保留至更新成功或主动隐藏。
- 生活分类、首页推荐等运营内容调整先预览，再点击统一发布。预览可按城市查看，自动推荐可查看不同时段的效果；待发布配置与当前生效配置区分，不在编辑过程中改变线上展示。
- 隐藏评价时一键选择常用原因，补充说明选填。保存审核人、时间、原因及状态变化；保留恢复公开入口，继续沿用现有评价检查与公开规则，未新增自动隐藏或自动通过策略。
- 本轮统一使用平台管理员权限，不按管理员／运营／审核／只读拆分角色，不增加对应的角色配置流程。平台账号管理与操作记录按同一套平台管理员能力设计。
- 数据口径已确认：统计排除作废单，下单数包含取消单并单列取消数量；主金额指标采用已完成订单额，进行中与取消订单额分别列出。金额来源为订单记录，不将其标为实收或结算收入。
- 图表金额刻度用「百万 ₫」，指标与明细显示完整金额。悬停、明细、导出保留原始精度，不用图表缩写金额重新计算合计。
- 批量选择先选本页，可明确切换为全部筛选结果。切换入口显示总数，已选范围始终可见；条件改变后重新明确选择范围，任务执行与失败重试针对已确认的记录集合。
- 后台菜单、按钮、校验与提示语支持中文／越南文／英文切换，默认中文；保留用户所选界面语言。界面语言与商家内容语言独立，切换界面不会覆盖已录入的商家资料。
- 经营开关按用户最新补充及后续范围确认：沿用现有「平台经营总开关＋每家商家的分项开关」。堂食／自取／配送等在各商家分别设置，平台设置不增加全平台三项业务分项总控。总控关闭时保留商家原设置，重新开启后按原分项配置生效，不批量改写商家选择。
- 批量导入的疑似重复商家默认跳过，运营核对后再选择处理，不默认补空字段或覆盖既有商家；其他已勾选有效行可继续建为草稿。
- 新增商家回收站与恢复入口，恢复后先隐藏，不自动公开。恢复资料保留历史关系，商家账号继续停用，后续在账号设置单独处理；重新展示按发布检查执行。

## FloShot 参考与平台后台新提案

用户指定 [FloShot 首页](https://fs.vkr.me/#home)。agent-browser 实际打开首页、功能目录、悬停卡片、展开并关闭大图；同时只读检查浏览器计算样式与动画。首页以深青蓝底、青色与蓝紫柔光建立氛围，内容区切换白底与深色文字。功能目录卡片使用小面积蓝／紫浅色渐层，悬停改变位置与阴影，导航随深浅区域调整。图片进入视区时有位移与透明度过渡，大图可展开。此处描述来自本次页面观察，后续网站版本可能变化。

平台后台的新提案保留原绿色 Logo，使用雾白工作区与白色侧栏。蓝色承载导航、链接、主动作和主趋势；青色、紫色用于稳定的业务分类和少量指标图标；琥珀用于待办，红色用于错误或危险。指标数字和表格正文保持深色，小面积浅蓝／浅紫提高层次。平台布局、图表、导航和业务流程根据现有功能自行设计，不复制参考站的品牌、版式、文案、图标和动画源码。

| 角色 | 本轮提议 |
| --- | --- |
| 页面／卡片／文字 | `#F5F7FA` ／ `#FFFFFF` ／ `#222936` |
| 信息与主动作 | `#416BD8` |
| 分类辅助 | 紫 `#7961C8`、青 `#288F95` |
| 待办 | 琥珀 `#A87925` |
| Logo | 原绿色文件，保持不变 |

首轮图包括运营总览与平台标签库，均为设计评审、示例数据。其后的精修已去掉 Logo 副标题、展开导航分组，并区分快速查看与完整编辑专页。当前图稿以 [统一18页评审入口](ui-review/platform-admin-redesign/review-index-20261105.md) 为准；早期语言必填星号不作为新规则。商家发布清单与中越文要求、图片20MB统一优化不留原图等采用下方最新确认记录。

用户选择流畅且有一定展示感的动效。最新建议：按钮和行悬停约 180–220 ms，选中条约 260–320 ms，编辑抽屉约 400–440 ms，图表数据切换约 500–560 ms，成功反馈约 200–240 ms。强调清楚的位移、图形连续变化与轻微层次变化，避免持续背景运动。数值到真实数据后才更新，刷新不滚动虚构数字；动效不延迟操作，不反复闪动，不改变表格列宽。减少动态效果时改为直接状态切换。以上为 YunQiao 的建议节奏，不是参考站参数的照搬。

本轮选定方向的图稿归档：[运营总览](ui-review/platform-admin-redesign/visual-direction-overview.png) · [平台标签库](ui-review/platform-admin-redesign/visual-direction-tags.png) · [内置 imagegen 生成说明与提示词](ui-review/platform-admin-redesign/visual-direction-prompts.md)。生成图仍为示例数据与初步字段，不作为实际权限、必填条件或指标口径的最终规格。
