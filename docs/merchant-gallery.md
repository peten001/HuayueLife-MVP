# 商家图库

门店外观（STORE）、商品/菜品（PRODUCT）、门店/用餐环境（ENVIRONMENT）没有图片张数上限。平台后台可多选上传，每个文件使用原图片上传接口逐张处理，单张 JPEG、PNG、WebP 仍限制为 5MB。

上传时显示已处理数量，某张图片格式无效、超过 5MB 或上传失败时，继续处理其他文件，最后列出成功和失败情况。所有文件发往最初选择的商家，避免切换页面时发往其他商家。

图片的排序与展示开关沿用原功能。后台给全部已开启图库图片标示展示顺序，不再标记“超出顶部图库展示上限”。小程序按分类保留全部已开启图片，并继续过滤隐藏图片、去重和懒加载。菜单图片仍按原用途在后台维护。

Logo、封面和替换单张图片仍使用单文件选择器。批量选择器仅用于新增图库图片，在更新选择器属性后再打开文件窗口。
