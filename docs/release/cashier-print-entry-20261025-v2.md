# 收银全部打印入口可用设备修正

- 日期：2026-10-25（越南时间）。
- 版本：`cashier-print-entry-20261025-v2`。
- 授权：延续同一打印问题的提交、推送和上线授权，用户要求继续修正订单入口并同步排查同类问题。
- 状态：本地验证通过，补发准备中；成功结果以后续实际验证记录为准。

## 问题与修正

第一版只修复顶部图标，实际订单打印组件及提交 Gate 仍然使用 USB 列表，因此出现图标显示可以打印、订单入口却显示没有设备／离线。本次移除两套可用状态，图标与操作统一使用 `availability`，设备选择统一使用 `readyPrinters`；任意已启用且服务端 `ONLINE`／readiness 为 READY 的 USB、Wi-Fi／网口、飞鹅或易联设备均可选择。

保留配置、开关、账号权限、断网、未知状态、重复提交与结果不确定保护。设备上线立即查询已有打印任务；当前选中设备离线或停用后，切换到剩余可用设备，全部离线则禁用。

## 同类问题排查

| 入口 | 结论 |
| --- | --- |
| 顶部图标与电脑／手机状态 | 改回读取同一可用状态，避免仅图标显示在线 |
| 电脑／手机堂食桌账 | 通过共享组件支持全部可用通道 |
| 到店自取、商家配送订单 | 通过共享组件支持全部可用通道 |
| 历史打印、设备选择与带原因补打 | 移除 USB 列表限制；保留原因与幂等保护 |
| 营业汇总 | 原接口已使用结账默认打印机，后端允许四种通道，无此限制 |
| 商家后台打印中心 | 原状态规则支持网络与云打印，无此限制 |
| USB 连接器专用同步／领取入口 | 按接口职责限定 USB，保持原边界 |
| 未选择桌账时的灰色占位按钮 | 原空态，不作为打印机离线处理 |
