## 行为

- 到店预约与商家配送使用同样的左右队列／详情布局，详情单独滚动，操作固定在底部；手机采用列表进入详情。打包自取仍在到店自取通道。
- 商家确认用餐预约时可回传桌号，也可先确认、后安排；已确认后可改桌或清除。顾客小程序预约列表及详情显示桌号，未入座前不提供点菜二维码。
- 预约桌台只是接待计划，允许安排当前占用桌台、同桌多个预约，不增加容量、时段或锁桌限制。当前用餐状态、点菜、金额及结账保持独立。
- 桌卡显示下一笔预约时间、人数、联系人及其他预约数量；桌账详情可查看全部未入座安排并进入对应预约。
- 空桌已有预约时，服务员首次点菜前收到提示。可以返回预约流程确认入座，也可确认继续开台接待其他客人；原预约保留，不合并预约顾客或预选菜。
- 预约入座仍只能选本店启用空桌；原桌尚在用餐时等候或换桌，不能加入另一组客人的账单。实际入座桌号同步顾客。确认／改桌不创建桌账、订单或厨房任务。
