## 当前规则

- 商家资料均可后补：店名、城市、行业、联系人、电话、中越英文、地址、定位、封面、介绍、营业时间、菜单／房型／服务等，不再作为建档或公开的必填门槛。未填店名时使用“未命名商家”。
- 保存草稿保持后台私有；运营勾选“本次发布后对外展示”并点击“保存并更新”后公开。资料缺项收进“可后补资料”，仅供参考，不拦截发布。
- 用户明确选择：未填城市但人工公开的商家，在所有已开放城市都可展示；填了城市的继续按所属城市展示。商家列表、推荐候选及运营预览采用一致的城市范围。已有商家在城市未改动时保留原归属。
- 平台图片和 XLSX／ZIP 导入包取消人为文件大小上限；相册、展示项目和标签不设数量门槛。上传文件流式写入私有临时目录，仍自动生成既有规格的 WebP 展示图和列表小图，请求完成或失败后清理上传原件。
- 图片以实际内容解码，支持可解码图片的自动优化；上传入口、页面大小判断和浏览器上传时限同步放开。三语文案和导入模板均更新为资料可后补。
- 展示、隐藏、停用、删除、认领和经营能力继续由相应人工操作决定；登录、记录归属和版本冲突等保护保持。

本规则替代 2026-11-06 发布中的“中越双语、完整行业资料后才能公开”及“照片 20MB、ZIP 50MB”要求。没有批量公开旧草稿、恢复已隐藏商家或改写已有经营开关。
