## 范围

电脑收银为轻柔叮咚，电脑 KDS 为两声短提示；堂食实际桌号、商家配送、到店自取支持中英越语音。各端独立保存开关、提醒方式、音量和试听。收银覆盖顾客扫码自动接单，厨房以用餐会话／订单与档口去重。具体规则见 [NEW_ORDER_AUDIO.md](../NEW_ORDER_AUDIO.md)。

收银和 KDS 各发布一套静态页面，运行时使用现行 899px 手机断点保持手机旧行为。手机不增加设置、不增加三类型声音，不改变原待接单和厨房数量变化触发。旧声音文件仅改导出名称，内容与发布前一致；原通知设置源文件完全恢复。电脑新开关只写新偏好键，不覆盖手机旧偏好。没有单独重打或发布 Android／iOS／小程序包。
