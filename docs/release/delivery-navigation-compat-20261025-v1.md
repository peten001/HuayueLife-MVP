# 配送 Google 导航兼容发布

- 日期：2026-10-25（越南时间）。
- 版本：`delivery-navigation-compat-20261025-v1`。
- 用户授权：提交、推送、上线；小程序继续由用户手动上传。
- 状态：源码已同步 GitHub main，收银与必要的 API 修复均已上线；手机／电脑现有订单只读验收通过。

## 交付范围

手机与电脑收银共用的配送地址入口，优先采用地址中的 WGS84 GPS 后缀，兼容越南等无 GCJ02 偏移地区订单独立保存的经纬度；无可用定位时显示灰色说明。Google 只按坐标搜索，不直接开始导航，复制只取地址正文。大陆坐标制式未知的历史值继续要求明确 WGS84 记录，避免错误转换。

同时提交前轮已确认的小程序原生普通地图选址、地址／坐标同步及进入地图前的轻提示。共享坐标区域和转换函数移入 shared，几何与计算不变。小程序不由服务器发布，仍由用户手动上传；数据库、KDS、商家后台和服务配置不在本次部署范围。API 的必要补发见文末，使用单独发布流程。
