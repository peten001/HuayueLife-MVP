## 实际部署

1. 提交本次源码，用确切提交构建候选并执行类型、构建及业务验证。
2. 备份数据库、当前 API／Linux 依赖、现有后台目录、原指针和配置；校验归档。
3. 在隔离数据库验证新增迁移与真实 API 流程；生产只允许预期的新增迁移。
4. 候选沿用原 Linux 依赖；只生成适配新增字段的 Prisma Client，不升级其他依赖。保留当前线上 API 的其余编译文件。
5. 验证生产总开关仍关闭后执行新增迁移，进行仅回环地址、无定时副作用的候选启动核对。
6. 原子切换 API／依赖指针并重启原进程；健康、鉴权及只读业务查询通过后切换平台后台。旧哈希静态资源保留，原上传目录不参与替换。
7. 服务器及外网分别校验资源与接口、经营关闭状态和受保护配置；发布结果、源码提交和回退位置补入本记录。

API 候选基于原 Linux 运行包，只改变 61 个允许范围内的编译文件；其余 831 个编译文件保持。依赖只更新 7 个生成的 Prisma Client 文件，Prisma 仍为 5.22.0，没有安装或升级其他依赖。迁移仅新增 `20261105090000_platform_review_reason`，原迁移记录和校验和不变；有效迁移从 48 项变为 49 项。

API 运行目录保持 `/opt/HuayueLife-MVP/apps/api`，入口保持 `dist/src/main.js`。一次正常重启后进程 `huayue-api` 在线，PID `3411961`、重启计数 `21`；网页补发没有再次重启 API。环境文件和原进程环境保持；环境文件 SHA-256 为 `bc7e0a955c42ce8896bb71a9491263fe32c65e9a7b16cb8cf69b8e7d9533fc38`。

## 回退原则

遇到非预期变化时恢复原 API／依赖／后台指针及必要的 Nginx 配置，不回滚营业数据库、不覆盖发布后产生的真实业务数据。新增可空原因字段保留兼容旧版；不通过重置开关、商家状态或账号来“修复”验收结果。

需要回退时运行服务器备份中的 `python3 /opt/backups/yunqiao-platform-admin-20261106-v1/deploy.py rollback`。脚本先核对仍属于本版本的指针及 Nginx 内容，再恢复旧 API／依赖与路由；不会覆盖其他后续版本或恢复数据库，也不会把用户后来主动开启的总开关关闭。该命令仅记录备用，本次没有执行回退。
