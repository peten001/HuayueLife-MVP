## 商家选择

- 必须为当前运营城市（北江/北宁）的 ACTIVE、客户端可见商家，具备可用的门店或商品图片。无城市时返回空推荐，不跨城猜测。
- 餐饮和咖啡各选一家，优先该行业的营业商家；全行业都休息时照片入口可展示休息商家并明确标注。“生活灵感”始终只选营业商家。
- 有 GPS 时优先该行业 5km 内的候选；缺店扩到 10km，再到当前城市。无定位时使用所选城市。客户端切换到其他城市不附带原城市的 GPS。
- 范围内按启用的 OPERATIONAL `FEATURED` 平台标签或后台手动热门推荐 `manualPopular`、真实评价均分、评价数量、距离、商家 ID 稳定排序。没有评价保持 null，不产生默认评分或随机评分。同样评分优先更多评价。
- 评分使用 ReviewsService 的相同公开规则：PUBLISHED；DIRECT 或未作废订单的 ORDER 评论。按商家一次分组聚合，不逐店请求详情。评分暂不可用时降级为位置和平台标签推荐。
- 餐饮使用菜品/商品照片优先，咖啡使用封面/环境优先；排除隐藏图片、菜单海报和执照。前端图片失败逐张回退，全部失败时隐藏卡片。
- 灵感若有其他合适候选，优先避免重复首屏商家；无其他候选可复用首屏商家。先选择时段表中的首选行业；不足两张时，尝试另一家符合当前时段的真实营业商家。两张灵感不重复同一家。晚餐/夜间的补位优先咖啡，再餐饮、KTV；其他时段只在该时段的首选行业范围内补位。第二张同类推荐使用不同且符合真实行业的文案，不将餐饮店标为按摩或 KTV。没有合适第二家仍只显示一张，不填入示例。

由服务端 UTC 时间换算到越南 UTC+7，不依赖手机时区。早餐必须为 NOODLE_SNACK 或餐饮商家明确勾选 `noodles_snacks`；正餐候选排除 COFFEE_TEA 和 CAKE，即使其使用餐饮详情模板。不通过店名推测早餐、菜系或服务。商家需要正确维护其营业时间和分类，自动推荐不需要新增专题或排期。

这是首页浏览推荐，不是系统通知或订阅消息。内容随着时段、城市/定位、商家营业状态、平台标签及评价数据变化；没有每天随机换店的规则。
