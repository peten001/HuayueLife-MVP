# 收银与 KDS 新订单声音 · 2026-10-22

状态：电脑收银和电脑 KDS 已提交、同步 GitHub main 并上线 `desktop-order-audio-20261022-v1`。手机保留旧行为，无数据库迁移、依赖或 API 改动。详见 [发布记录](release/desktop-order-audio-20261022-v1.md)。

## 2026-10-27 KDS 提示音统一

用户要求 KDS 改为收银同款提示音。电脑两端现复用同一组 784 → 622 Hz 下降叮咚音，音高、时序和持续时间相同，避免配置再次分叉；收银自身提示音、KDS 的“请制作”语音及各端独立设置保持。手机沿用原声音。仅需发布 KDS 静态页面，收银线上版本不切换。发布候选 `kds-doorbell-20261027-v1`，最终状态见发布记录。

## 设置入口与隔离

- 电脑收银：顶部声音图标 → 新订单声音设置。
- 手机版本保持原版，不增加新的声音设置；原通知设置源码完整恢复，仍使用发布前的通用提示音及待接单触发。
- 电脑 KDS：厨显设置内的新订单声音；顶部声音图标打开本端厨显设置。手机尺寸不显示新增设置，沿用原声音开关和厨房任务数量变化监听。
- 收银只显示收银声音，KDS 只显示 KDS 声音。没有跨端声音配置页面。
- 电脑两端按设备分别保存开关、提醒方式和音量，不写入门店 KDS／传菜开关，不改写手机原有 sound_enabled 偏好。
- 新设备默认声音关闭；迁移本端原来的 sound_enabled 偏好，不复制到另一端。
- 提供仅提示音、仅语音、提示音加语音，音量 0–100，三类订单分别试听。试听会启用当前端声音，且不创建业务订单。
- 关闭立即停止尚未完成的声音和排队播报。切换语言清除旧语言的播报队列。

## 电脑与手机发布边界

网页共用静态部署，运行时沿用现行收银 899px 手机断点隔离声音通道。900px 及以上启用本轮电脑功能，手机使用逐字保留的原声音实现（仅改导出名称），原通知设置文件与发布前完全相同。手机不新增三类型播报、设置和去重逻辑；电脑声音开关也不会覆盖手机旧偏好。电脑／手机之间调整视口会关闭电脑设置并停止电脑播报。无新 Android／iOS 包或小程序发布。

## 提醒内容

| 新单类型 | 收银 | KDS |
| --- | --- | --- |
| 堂食 | 02桌有新订单，请查看 | 02桌有新订单，请制作 |
| 商家配送 | 有新的商家配送订单，请查看 | 商家配送新订单，请制作 |
| 到店自取 | 有新的到店自取订单，请查看 | 到店自取新订单，请制作 |

桌号使用实际订单数据；无桌号回退堂食新单通用文案。提示和语音支持中英越，跟随当前界面语言。收银与 KDS 均使用相同的轻柔下降叮咚音，由 Web Audio 合成，不复用第三方 APK 音频。语音使用设备提供的 SpeechSynthesis 语音，不引入付费服务。

## 触发与去重

- 收银：成功读取完整实时订单列表后建立静默基线，再识别新的待接单订单和顾客扫码自动接单的堂食订单。服务员自行录入的订单静默记录。
- 单独查询待接单、详情或改单快照不能提前建立完整列表基线；之后的改单也不会重复播报已有订单。
- KDS：成功读取厨房看板后建立静默基线。开启 KDS 时，仅提醒当前档口首次收到且仍需制作的新单任务。
- 同一轮多道菜、多档口合为一次；全部档口模式按厨房桌单合并。堂食使用用餐会话识别，新建同桌加菜子单不冒充新桌单；旧订单无会话信息时回退订单 ID。
- 指定档口按厨房桌单与档口去重，其他档口任务静默记录，切换筛选不会重播。新档口后续首次收到任务可提醒该档口。
- 搜索、标准／汇总／订单进度切换不影响监听范围，不触发声音；加数量、已处理订单重新出现、退菜和传菜不触发新单提醒。
- 首次加载和刷新页面不播报已存在订单。按商家与终端保存最近 5000 个去重键，恢复时读取 30 天内记录；当前会话保留已观察键，避免大看板超过持久化上限后反复播报。
- 多张新单顺序播报，不以 cancel 覆盖上一张；排队超过 30 秒的旧提醒丢弃，避免后台恢复后积压播报。声音关闭或未激活期间不补播。
- 原有用餐预约提醒沿用其原触发与通用播报；本轮没有新增预约、加菜、退菜、超时、支付专用声音。

## 浏览器边界

浏览器需要用户点击启用或试听后才能播放。刷新后保留配置，界面明确提示重新激活，顶部不会把尚未解锁的声音显示为已开启。音量为零单独提示；声音权限、设备语音不可用等错误直接显示在本端声音设置里。后台网页暂停及系统音量限制仍受设备规则约束。
