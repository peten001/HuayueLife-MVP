# Merchant Admin · 正式分析首页与管理页完全重构

日期：2026-09-06。范围：商家后台 UI；本地隔离验收。未 commit、未 push、未部署。

## 本轮依据

用户最终明确：首页不再重做图表，直接使用此前线上正式经营分析页，桌面与手机一致；菜品、订单、结账及更多中的管理页面完全重构，但功能、权限、接口和业务口径不动。管理页采用正式分析页的浅鼠尾草与近白配色，并以 Apple 工具型产品的安静层级、连续记录和逐层详情组织。结账只查看记录，收银执行仍由 Cashier 负责。

Mouse-lin 的 [Finesse Brief](https://github.com/mouse-lin/finesse-brief) 用于现有结构审查、功能映射和交互边界；[Finesse UI](https://github.com/mouse-lin/finesse-skill) 用于产品界面、图表、字段分组、响应式与截图复核。[Frame Smith](https://github.com/mouse-lin/frame-smith) 已核对，但它负责视频制作，本轮没有视频交付，不引入 Remotion 或其他无关依赖。

## 已实施的结构

| 页面 / 状态 | 内容与操作重构 |
| --- | --- |
| 首页 / 经营分析 | `/dashboard` 与 `/business-analytics` 直接复用此前线上正式 `BusinessAnalyticsPage` 与正式图表，不另建摘要、不重新包装图表；桌面与手机均呈现完整分析内容。 |
| 菜品目录 | 桌面分类侧栏 + 固定六列清单；手机连续图文目录，点击整行进入详情；多语言名称和分类受列宽约束，完整内容在 title / 详情可读。 |
| 菜品详情 / 编辑 | 详情抽屉分为图片、名称、价格、供应状态；编辑为分组表单与预览，手机全屏抽屉，保留单位、上下架、售罄、删除确认和原保存接口。 |
| 分类管理 | 分类目录与名称 / 排序编辑区域分开；保留招牌菜保护、启停与原接口。 |
| 订单 | 筛选区、正常/作废切换、时间与桌台、状态、金额分列；手机采用单据流水。详情为主单据与金额 / 处理记录分区。 |
| 结账与收款 | 收款总额、现金 / 银行分布和结账流水分层；详情区分最终实收、折扣抹零与来源订单；保留返回链，不增加收款动作。 |
| 已作废记录 | 流水行进入审计详情抽屉，保留原因、操作人、原始财务与影响范围；未物理删除历史证据。 |
| 桌台 | 按状态筛选的桌台概览；账单抽屉明确单价、数量、小计；创建、编辑、二维码操作进入统一弹层；不执行收银。 |
| 员工 | 团队名录、角色状态、访问信息；新增/编辑弹层与二级操作，保留店主和角色限制；保存错误在弹层内可读。 |
| 店铺设置 | 营业时间、配送、公告、资料、账户安全分区；切换保留未保存草稿；多时段、次日与现有校验 / 保存不变。 |
| 打印中心 | 紧凑可展开的设备状态；设备目录、打印流水与详情；配置与预览分区，手机切换设置/预览。打印详情与确认支持原生弹层嵌套；重试、补打和设备状态门禁未改变。 |
| 更多 / 登录 / 无权限 | 分组目录与账号区域、统一登录表单和受限提示；不变更登录接口或鉴权。 |

旧打印兼容入口继续受原灰度开关控制；平台后台、Cashier、小程序和后端 API 未改。本轮没有凭 KiotViet 样例新增客户数、库存、采购、完整资金账簿或其他不存在的业务模块。`/merchant/profile/change-password` 目前仍是已有重定向，账户安全在店铺设置内；路由覆盖数不等于独立页面数。

### UI Skills 检查说明

最终只运行一次 Impeccable detector。它把带 `v-if`、动态 `src` 和失败回退的 Vue 图片绑定标为可能 broken image；这些路径已由真实浏览器的正常图、失败图和占位状态覆盖。其余提示主要是 DESIGN.md 主色板之外的语义色：一类来自用户要求原样保留的正式经营分析，另一类来自危险/警告、遮罩和热敏小票预览。它们是有业务含义的例外，本轮不为消除静态提示而改坏正式页或打印语义。

Impeccable 独立 reviewer 只发现一个新的可复现问题：STAFF 的 `/dashboard` 实际显示“更多”目录，但旧路径判断误套分析样式域。已改为同时判断 OWNER / MANAGER 分析权限，并在 390px 角色回归中确认 STAFF 使用管理页样式、不发起分析请求。除此之外 reviewer 未发现新的本地验收阻断项。

## MENU MANAGEMENT

| 宽度 | 编辑 / 删除无需横向滚动可见 | 菜品表格横向滚动 |
| --- | --- | --- |
| 1440 | 是 | 无 |
| 1280 | 是 | 无 |
| 1024 | 是 | 无 |

实际采用：收紧分类侧栏；主容器 `minmax(0,1fr)`；六列固定宽度分配；名称/分类截断与完整 title；紧凑数字、状态与操作列；手机转换为目录行 + 详情抽屉。没有依靠 sticky right 掩盖超宽表格。手机分类条允许受限的分类浏览，不产生整页横向滚动。
