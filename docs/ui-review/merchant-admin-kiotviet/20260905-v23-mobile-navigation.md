## 1. 已确认导航

底部顺序严格为：**首页 / 菜品 / 订单 / 结账 / 更多**。

| 入口 | 页面职责 | 主要点击链 |
| --- | --- | --- |
| 首页 | 直接展示经营分析：营业日与区间、主要指标、资金、趋势、时段和菜品表现 | 日期 → 分析；有效金额 / 笔数 → 结账记录；区间 → 选营业日 → 明细 |
| 菜品 | 分类、搜索、排序、状态与现有商品 / 分类管理 | 分类或筛选 → 图文行 → 资料 / 编辑 → 返回原列表；新增、上下架、售罄、删除保留现有规则 |
| 订单 | 原订单查询与管理，正常 / 已作废记录分开 | 营业日 / 状态 / 类型 / 搜索 → 原单详情 → 有权限的管理动作 → 原位置 |
| 结账 | **只查看已有结账与收款记录** | 营业日 → 有效结账汇总 / 列表 → 结账详情 → 关联原单；不执行收款结账 |
| 更多 | 现有桌台、经营设置、打印、员工账号、语言、密码与退出等分组目录 | 分组入口 → 现有页面 → 返回目录原位置 |

权限与能力限制仍优先，五个位置是 OWNER 的完整结构参考，不给 STAFF 新增菜品、分析或财务访问权限。

## 2. 日期筛选

采用用户截图的 **顶部日期入口 → 底部日期面板 → 自定义日历** 结构。

- 分析首页：今日、昨日、近 7 天、本月、上月、自定义；通过现有 `dateFrom / dateTo` 表达，不新增接口。
- 默认“今日”跟随服务器当前营业日，不直接采用手机自然日，跨天开台归属不变。
- 选择快捷日期后查询；关闭 / 返回不应用新条件，原选择保留。
- 自定义需起止校验，确认后应用；取消则回原范围。
- 订单 / 结账现有接口按单日 `date` 查询：展示今日、昨日、选择营业日等适用控件，不画支持多日却只加载某一天的假筛选。若用户要求多日订单 / 结账全量查询，应另行评估接口范围，不能在 UI-only 本轮偷加。
- 菜品顶栏采用分类、搜索、排序、状态，不放没有业务意义的日期筛选。

## 3. 根据六张参考图采用与不采用的内容

### 首页与日期面板

采用：品牌 / 页面区域、日期入口、紧凑多指标汇总、纵向经营图表分组、数据卡片的明细入口、底部日期选择和选中标记。

不直接复制：电话、通知、支持入口，多门店切换，贷款 / 库存 / 采购 / 客户等快捷入口，以及尚未核实的客户数和桌台覆盖率。YunQiao 只显示已有真实指标，结账笔数不能冒充客流。

### 菜品

采用：顶部标题与搜索 / 排序，分类横向切换，图文信息行、右侧价格、细分隔，新增按钮避开底部导航与价格区。

当前代码确有分类、价格排序、名称排序、默认顺序、状态与单位字段，可以复用；不照搬参考图库存数量、库存总量或未经核实的独立 SKU 编码。次要语言可截断，但详情应可看完整内容。

### 订单

采用：顶部条件、查询汇总、按记录组织的列表、金额和时间 / 桌台 / 类型分层、点击进入独立详情。

原单金额不标成净营业收入。已取消记录可按原有查询规则查看，但不能计入有效经营收入；已作废与正常记录明确区分。

### 结账与收款记录

用户已回答：**查看结账与收款记录，不执行收银操作。**

参考图 `Sổ quỹ` 实际是资金账簿，包含现金 / 银行 / 总账、账户、期初、收入、支出、期末和新增流水。本轮不把这些无对应证据的账簿能力照搬进来。

YunQiao 第四栏显示已有净收、有效结账笔数、现金 / 转账分组与结账列表；金额分组只读，不伪装成独立支付凭证或账户流水。没有“立即结账”“收款”“新增流水”按钮，也不增加账簿期初 / 期末 / 支出字段。

### 更多

采用：顶部账号摘要，按业务与设置分组的小图标 + 名称入口，必要时两列，纵向可滚动。

只承接已有模块。参考图的合同、第三方配送平台、价目表、退款体系等不直接复刻；账号资料不复制参考截图的真实号码。

## 4. 主屏幕使用约束

- 是 Web 独立窗口，不绘制假状态栏 / 刘海 / 浏览器后退按钮。
- 底部五栏均有文字和清晰点击区；主内容底部留导航与系统安全区空间。
- 详情、编辑、筛选均有应用内返回或关闭，保留日期、分类、搜索、分页与位置。
- 日期面板覆盖底栏时需真正阻止点击背景；表单有修改时按真实脏状态提示退出。
- 软键盘不能遮住输入与主操作；窄屏长中越英文本、VND 大金额和底部新增按钮单独验收。

## 5. 交付与边界

本轮生成首页 / 日期 / 菜品，以及订单 / 结账 / 更多两组审核图，示意同一套五栏结构。图稿只有示例数据；不能把静态箭头和按钮当作已实现的交互。

图中条目为布局节选，数字不是跨页面对账样本；后续实现必须使用统一的真实接口响应。已取消原单可在原单记录中查到，不计入有效结账收入。生成图的精确字形、曲线坐标与屏幕比例不替代正式组件验证。提示词和定向修订见 [生成记录](20260905-v22-v23-image-prompts.md)。

页面源码、API、权限、订单状态机、数据库、Cashier 与 MiniApp 均未改动。完整功能和主屏幕真机验收仍在获批后的本地实现阶段；当前不 commit、push 或上线。
