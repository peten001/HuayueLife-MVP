## 本地入口

- 电脑：http://localhost:4198/dashboard
- 同 Wi-Fi 手机：http://192.168.1.6:4198/dashboard
- 自动使用本地店主示例账号，无需生产登录。顶部黄色条明确标记“本地隔离验收”。
- 手机在 Safari 打开后，使用“分享 → 添加到主屏幕”，再从新图标打开。不要使用原线上后台图标；两者地址与数据不同。
- 电脑需保持开机、本地服务运行。网络变化可能改变手机地址；重新启动会打印当前地址。
- 重启：仓库根目录执行 `corepack pnpm --filter @huayue-life/merchant-admin dev:acceptance`。重启会重置示例编辑。

## 已实现

- 桌面与手机首页都直接使用此前线上正式经营分析页：正式日期筛选、经营指标、资金概览、AI 简报、营业趋势、时段热力、TOP5、营额占比和经营建议完整保留，不再建设另一套摘要或重做图表。
- 首页样式与其他管理页严格隔离；菜品、订单、结账、桌台、员工、设置和打印采用正式分析配色与 Apple 风管理结构，不让新外壳污染正式分析内容。
- 店主五栏：首页 / 菜品 / 订单 / 结账 / 更多。原 OWNER / MANAGER / STAFF 与能力开关继续限制入口和路由；普通员工不请求无权限的经营分析。
- 统一营业日日期弹层：今日、昨日、近7天、本月、上月、自定义；记录查询维持现有单营业日 API。分析多日范围先选择具体营业日，不偷取最后一天当整段明细。
- 结账页只读财务记录，新增当日收款概览来自原有订单汇总接口；原单金额、最终实收、所属营业日与实际结账时间分开显示。
- 分析 → 结账 → 原单 → 返回保持日期；分析返回恢复展开状态及滚动位置，原单查询保留搜索 / 页码。保留记录十秒刷新、订单详情五秒刷新与未读消息提示。
- 菜品手机连续列表，点击“管理”展开原状态 / 编辑 / 删除；分类手机列表同步适配。编辑采用原生弹层、焦点回到原触发按钮。
- 更多集中现有桌台、店铺设置、员工、打印。原管理 API 与表单保存处理保持；桌台仅查看账单，收银端执行结账。打印任务手机改紧凑记录，小票预览按可用宽度缩放，打印协议与出纸设置不改。
- Merchant PWA 启动色与页面浅背景一致；安全区、输入 16px、44px 手机触控、减少动态和应用内返回纳入实现。

## 本地环境边界

- 隔离服务没有生产代理，示例数据不是真实店铺账目。菜品 / 分类 / 桌台 / 员工的支持操作只改内存；未模拟的 API 明确报“本地隔离环境未启用此操作”，不假装保存成功。
- 不创建实际打印任务、支付、收银操作；真实设备绑定、实际出纸、真实聊天、上传服务与生产数据对账不是这次隔离预览的通过项。
- 菜品包含一张本地标识测试图、一张失败图片路径与无图状态，用于验证图片布局和回退，不冒充真实菜品图。
- HTTP 局域网预览仅在本地注入安全随机 UUID 兼容函数，便于打开作废预览；生产仍使用原有 HTTPS 原生实现。HTTP 预览不能证明所有 HTTPS / PWA 安装能力。
- 不新增 KiotViet 的库存、客户、借贷、支付凭证、分店等业务。
- 未 commit、未 push、未部署；无生产写操作；Cashier / MiniApp / API / 数据库源码未改。
