## 已确认流程在图中的体现

- 统计排除作废单；下单数含取消，主金额为已完成订单额，进行中／取消订单额另列。图表用百万 ₫，指标／明细用完整金额。
- 商家最少店名＋城市保存草稿，按行业资料齐全且中文／越南文齐全后公开。已展示但资料不齐的旧商家保留展示并列入待完善。
- 图库张数放开；源图单张20MB、统一自动优化、服务器不留上传原图，失败可单张重试。标签可新增／修改，公共标签改名影响全部关联商家，显示影响数量。
- 内容运营先预览，再统一发布；草稿与当前生效内容区分。
- 评价隐藏一键选常用原因，说明选填。平台账号统一管理员权限。

## 已完成的后续确认

1. 后台界面中越英切换，默认中文；商家内容语言单独维护。
2. 本轮只做平台电脑后台。
3. 经营设置沿用平台总控＋每家商家分项；不新增全平台三项业务分控。
4. 重复导入默认跳过并核对；单张源图20MB统一优化不保留原图；回收站恢复后隐藏。
