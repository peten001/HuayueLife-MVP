## 本组采用的最新规则

- 平台设置只有经营总开关。各家商家的堂食、自取、配送等单独设置，保持原层级与独立存储。总控关闭时保留商家设置。
- 菜单、按钮、校验与反馈可切换中文／越南文／英文，默认中文。当前截图为中文模式，未另生成整套越文／英文截图；实现时需要覆盖长文本与各状态。
- 本轮只做电脑后台。商家后台、收银、KDS、小程序与手机后台重构不在本轮范围。
- 新上传单张源文件20MB以内，统一自动优化，展示观感以现有照片为基准，仅存优化展示图和小图，不存原件。此前“可切换原图不压缩存储”的图稿结束评审。
- 疑似重复导入默认跳过，核对后再选择处理；有效行继续建草稿。
- 删除资料保留，新增回收站恢复入口。恢复后先隐藏，账号继续停用，重新公开按发布检查执行。

## 仍在设计评审的内容

主要入口已经具备对应图稿。列表、表单、抽屉与内容发布页的加载、空、错误、长文本、部分失败与重复提交状态，按蓝图共用组件规格继续落实，不能将生图当成功能已实现的证据。服务诊断子页、平台账号子页和操作记录的字段细节，依据真实接口能力进一步校对。

行业／标签词典中的可选语言和排序等默认值保留当前规则；商家对外资料的中越文齐全要求另行按已确认发布清单执行。次级图中的样例行业数量、商家数量不改生产字典。
