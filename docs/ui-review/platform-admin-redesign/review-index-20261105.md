## 当前确定的方案

- 品牌：原绿色Logo＋YunQiao，无副标题；雾白、蓝色主操作、紫／青辅助色；导航分组始终展开。
- 列表：右侧快速查看，完整编辑进入专页；高级筛选折叠；返回保留条件与位置；本页选择明确扩展至全部筛选结果。
- 数据：总览看今天，分析近7天对比前7天；排除作废，下单含取消；已完成订单额为主，进行中与取消金额另列；图表百万₫，指标与明细完整金额。
- 商家：店名＋城市即可建草稿；按行业清单与中越文齐全后公开，英文选填；旧已展示资料不齐商家继续展示并列待完善。
- 变更：商家保存并更新或另存草稿；内容运营先预览再统一发布；公共标签改名影响所有关联商家并显示影响数量。
- 图片：张数放开、单张源图20MB、统一自动优化、服务器不保存上传原图，以现有照片观感为基准。
- 经营：平台保留现有总控，各商家堂食／自取／配送等分别设置，总控关闭保留分项配置。
- 运营：重复导入默认跳过并核对；评价隐藏一键选原因、说明选填；平台统一管理员权限；回收站恢复后隐藏。
- 范围：仅平台电脑后台，中越英界面切换／默认中文；其他端不进行本轮重构。
